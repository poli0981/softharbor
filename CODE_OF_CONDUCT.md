# Code of Conduct

This project follows the **[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**.
Please read it there; it applies in full and is not restated here.

It covers every project space — issues, pull requests, commit messages,
discussions — and any place someone is representing the project.

Reports go to **contact@softharbor.net**. They are read by the maintainer
(@poli0981) and are not shared further. If your report concerns the
maintainer, say so and you will get a plain answer about what can be done,
rather than a process that reviews itself.

Enforcement is at the maintainer's discretion and can range from an edit
request to a permanent ban. [CONTRIBUTING.md](CONTRIBUTING.md) lists the
specific behaviours that are closed without discussion — read that first if
you are about to open a pull request.

Security vulnerabilities are **not** a Code of Conduct matter: see
[SECURITY.md](SECURITY.md).
